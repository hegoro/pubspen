Política de privacidad

Última actualización: 21 de octubre de 2026

PersonalSpencesApp es una herramienta de uso personal. Su único usuario es su autor, con su propia cuenta de Google.

Datos a los que accede

  • Gmail (solo lectura, gmail.readonly): lee únicamente los correos cuyo asunto contiene "DAVIbank en Linea", para extraer comercio, monto, fecha y hora de cada compra. No modifica, etiqueta, envía ni borra correos.
  • Google Sheets (spreadsheets): crea y actualiza un Google Sheet privado del usuario donde se registran los gastos.

Uso y almacenamiento

  • Los datos se procesan en el computador del usuario y se guardan solo en su propio Google Sheet.
  • Los tokens de acceso se guardan localmente en el computador del usuario.
  • Para categorizar los gastos, se envían únicamente los nombres de los comercios a la API de Anthropic (Claude). No se envían montos, fechas, datos de tarjeta ni el contenido de los correos.
  • Los datos no se venden, no se comparten con terceros para publicidad y no se usan para ningún otro fin.

Google API Services User Data Policy

El uso y la transferencia de información recibida de las APIs de Google cumplen con la Google API Services User Data Policy, incluidos los requisitos de Limited Use.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.

English summary: PersonalSpencesApp is a single-user personal tool. It reads (read-only) DAVIbank purchase notification emails from its owner's Gmail and records them in the owner's private Google Sheet. Only merchant names are sent to the Anthropic API for categorization. Data is never sold or shared. Use of Google user data complies with the Google API Services User Data Policy, including Limited Use requirements.
